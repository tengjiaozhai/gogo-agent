# 014 意图种子与 Qdrant L2 检索

## Java 基线与 Python 实现

Java `IntentRouterKnowledgeConfig` 在启动时将 `intent-seed.yml` 样例用 `qwen3.7-text-embedding`（1024 维）写入 `InMemoryStore`。Java `IntentVectorMatcher` 取 Top-2、命中阈值 `0.75`、跨类别前两名分差 `<0.05` 时弃权，`≥0.85` 为高置信。基线文件位于 `/Users/shenmingjie/workSpace/LLMentor-teach/gogo-agent/src/main/java/com/gogo/travel/` 的 `config/IntentRouterKnowledgeConfig.java` 和 `agent/intent/IntentVectorMatcher.java`。

Python 的 [`seed.json`](../../src/gogo_agent/intent/seed.json)保存移植的 16 类、68 条运行时样例。[`IntentSeedCorpus`](../../src/gogo_agent/intent/vector.py)检查类别覆盖、重复和与 L1 的重叠。`IntentVectorIndex` 使用 AgentScope 2.0.8 `KnowledgeBase` + `QdrantStore`，样例 `Chunk` 带 `intent` 和 `seed_version`。语料、模型、维度和人工版本共同决定集合名；变更后切换物理集合，不混用新旧向量。重复构建校验内容后复用；断点写入可按固定文档 ID 与序号补齐。同名集合维度或内容不符会报错。

查询前先检查集合与完整性，避免 AgentScope `KnowledgeBase` 自动创建空集合。`IntentVectorMatcher` 保留 Top-2 分数与样例证据：低于阈值返回 `miss`，跨类别近分差返回 `ambiguous`，其余命中转成 008 单意图结果。HTTP 编排现由 [017](016-017-执行与流水线.md) 接入真实 L1/L2。

## 配置与构建

`.env` 的 `GOGO_MODEL_API_KEY` 和 `GOGO_MODEL_BASE_URL` 同时供聊天与 embedding 使用。L2 额外指定 `GOGO_INTENT_EMBEDDING_MODEL=qwen3.7-text-embedding`、维度 `1024`、Qdrant URL、索引版本和判定参数；模板见 [`.env.example`](../../.env.example)。脚本给网关根地址补 `/v1`。Qdrant 按用户提供的 `QdrantStore(url="http://172.22.22.123:6333")` 连接。

```bash
.venv/bin/python scripts/build_intent_index.py --probe
```

脚本最多每批 10 条 embedding，写完 68 条后输出状态；再次运行应为 `reused`，不会重新向量化。`--probe` 打印固定句的 Top-2。同一集合只运行一个构建进程；AgentScope 2.0.8 的首次建集合是先检查再创建，同时启动两个进程可能让其中一个遇到创建冲突。旧集合不会自动删除，确认新集合切换成功后再按运维需要清理。
