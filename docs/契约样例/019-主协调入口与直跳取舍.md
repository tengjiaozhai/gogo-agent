# 019 快速命中仍进入主协调入口

## 现行决定

普通新请求统一经过认证、业务消息保存与 017 意图流水线，再进入主协调入口；**L1/L2 的高置信结果不触发子 Agent 直跳**。Java 的 [`AgentPipelineService.dispatchByIntent`](</Users/shenmingjie/workSpace/LLMentor-teach/gogo-agent/src/main/java/com/gogo/travel/agent/service/AgentPipelineService.java>) 中，`tryPlanDirectDispatch()` 和 `dispatchSubAgentDirectly()` 的调用仍被注释，实际执行 `masterAgent.call(buildMasterInput(...))`。辅助直跳代码虽仍在 Java 类中，却标为弃用，不能按旧文章的早期方案理解为现行行为。

选择统一入口的关键场景是跨 Agent 续聊：用户在差旅管理角色中得知目的地是上海，下一句问“那里天气怎么样”。即使天气词让 L1 命中信息查询，第一次进入 InfoAgent 时它也可能没有前一个角色的上下文；只有分类标签并不能提供“那里=上海”。原 [019 指引](</Volumes/PortableSSD/docs/tengjiaozhai.github.io/thoughts/019_✅用户意图很明确时，直接路由给子智能体还是主智能体？.md>)明确废弃了优先直跳方案，选择先保证上下文完整。

## Python 当前落点

[`ChatAgentExecutor`](../../src/gogo_agent/chat/executor.py) 目前只有一个 HTTP 对话协调入口 `GoGo`，**尚无真正注册子 Agent 的 `MasterAgent`**；它在阶段 C 的 023 实现。019 固定当前可验证的运行选择：无论识别来自 L1、L2 还是 L3，都会调用同一个 `GoGo` Agent；`extra.intent_pipeline.dispatch_target` 记录 `GoGo`，不按 `confidence=high` 另选执行角色。缺上下文而未调度时该字段为 `null`。识别层的有序类别进入该 Agent 的提示词，但提示词明确说明类别不是身份、审批或下单授权，当前 Agent 也没有业务写工具。多意图执行的 [`OrderedMasterCoordinator`](../../src/gogo_agent/intent/execution.py) 仍只是 016 的假子 Agent 验收边界，没有接入 HTTP。

因此，本项完成的是**路由策略与当前协调入口的验收**，不声称 Python 已完成 Java Master→子 Agent 的真实调度。023 接入 Master 后，应复用此策略，并补一条从 HTTP 经 Master 到只读子 Agent 再返回用户的运行验收。

## 直跳仅作为后续优化候选

| 条件或结果 | 启用前需证明 |
| --- | --- |
| 可能收益 | 跳过一次 Master 推理，减少相应延迟与 token；需要在相同业务语料上实测，不以类别高置信代替收益证据。 |
| 单意图与目标 | `multi_intent=false`、恰有一项、置信度高、目标子 Agent 已真实装配且在明确白名单。Java 旧辅助逻辑的白名单只有 InfoAgent。 |
| 跨角色上下文 | 本轮问题自包含，或子 Agent 能得到经过归属校验的完整必要上下文；“那里天气”等跨角色指代不得因高置信直接丢失目的地。 |
| 权限与写入 | 服务端身份、会话归属、工具权限和写操作确认/幂等在子 Agent 工具边界继续生效；初期只考虑无业务写能力的独立只读任务。 |
| 结果与故障 | 子 Agent 结果仍经统一整合、保存、SSE/JSON 和错误处理出口；失败回到 Master 时必须保留原问题、改写结果和意图信息。 |
| 移除条件 | 任一必要条件、跨角色回归或直接收益不成立，就不启用直跳分支。 |

这只是将来可评估的方案，当前没有直跳配置、白名单、备用分支或双轨调度。

## 验收

运行 `.venv/bin/python -m pytest -q tests/test_019_routing.py`。测试让 L1 `flight_search`、L2 `approval_query` 和 L3 有序双意图分别走 JSON/SSE：三者都进入同一个 `GoGo`，保存的助手消息也标记 `dispatch_target=GoGo`；高置信不会绕过协调提示词。另用已建立的会话验证另一用户以相同快速问题发送消息仍获 403，且不会构造 Agent。该验收不能替代 023 的真实 Master/子 Agent 工具调用测试。
