## 运行边界

[`model.py`](../../src/gogo_agent/model.py) 为 HTTP Agent 和意图流水线创建 AgentScope `OpenAIChatModel`，使用同一个 OpenAI 兼容 Chat Completions 网关，关闭 AgentScope 与 SDK 两层自动重试。意图模型保持非流式、`temperature=0`、`max_tokens=2048`、JSON 响应；GoGo 的流式或非流式由 HTTP 入口决定，InfoAgent 非流式。AgentScope 的 DeepSeek 适配器会额外发送供应商专用 `thinking` 请求体，026 的跨模型工厂改用通用适配器；目标网关对各具体模型的真实支持仍需带凭证调用验证。

每次实际 `ChatModel.__call__` 完成时，Uvicorn 的 `uvicorn.error` INFO 日志记录 `role`、`model`、`duration_ms`、`input_tokens`、`output_tokens` 和 `status`。流式调用在消费到最终响应或提前关闭时记录；usage 缺失时 token 记为 `unavailable`，不当作 0。日志不读取 API key、提示词、用户消息或模型响应文本。这里的耗时是调用方观察到的墙钟时间，包含框架包装与流式消费；`ChatUsage.time` 是供应商适配器自己的计时，两者不必相等。日志中的 token 可用于观察调用量，本项不计算实时价格或总费用。

## 离线验收

```sh
PYTHONPATH=src .venv/bin/python scripts/demo_026_model_roles.py --case all
.venv/bin/python -m pytest -q tests/test_026_model_roles.py
```

脚本用固定 `_call_api` 响应触发真实 L3、模型工厂、调用记录与内存会话归属代码，不连接外部网关；可按脚本顶部的 Java/Python 对照和断点顺序单步运行。测试覆盖主/稳定档选择、两层重试为零、usage 存在/缺失、日志不含密钥或消息、显式空白稳定档拒绝以及切换主模型后用户和仓储不变。现有 023/024 测试继续验证 HTTP 工具和失败出口。未通过真实 Qdrant、网关或价格接口验证模型可用性与费用。
