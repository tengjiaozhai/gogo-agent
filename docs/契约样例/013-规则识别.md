# 013 L0/L1 确定性意图规则

[`IntentRuleMatcher`](../../src/gogo_agent/intent/rules.py)移植 Java `IntentRuleMatcher` 的有序规则、排除词、L0 强连接词守卫与 L1 子句级跨职责歧义判断。16 类意图中，`unknown` 不设关键词；`itinerary_planning` 有两条不同优先级的规则。规则只负责识别，不触发业务写入。

执行顺序：`QueryInput` 先拒绝空白输入；句长至少 10 且较靠后的强连接词出现时，L0 返回 `ambiguous`；否则 L1 逐子句识别，不同职责组均命中也返回 `ambiguous`。问候加单任务只保留任务。最后按全句规则顺序取第一个未被排除词挡住的命中，否则 `miss`。

| 输入 | L1 结论 | 原因 |
| --- | --- | --- |
| `差旅政策是什么` | `policy_query / hit` | 明确政策词 |
| `报销政策中住宿标准是多少` | `policy_query / hit` | 报销规则被“政策/标准”排除 |
| `取消订单` | `booking / hit` | 供应商订单操作 |
| `查一下订单` | `miss` | 无法断定订单类型 |
| `查下差旅政策，帮我报销发票` | `ambiguous` | 政策和报销分属不同职责组 |
| 空白输入 | 校验失败 | 不进入匹配器 |
