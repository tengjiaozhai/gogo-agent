### [x] 011 用改写融合多轮对话 · [原文](</Volumes/PortableSSD/docs/tengjiaozhai.github.io/thoughts/011_✅通过问题改写融合多轮对话.md>)

### [ ] 015 L1/L2 多意图支持 · [原文](</Volumes/PortableSSD/docs/tengjiaozhai.github.io/thoughts/015_✅L1_L2意图识别针对多意图的支持.md>)

### [ ] 016 单次对话多意图执行 · [原文](</Volumes/PortableSSD/docs/tengjiaozhai.github.io/thoughts/016_✅单次对话多意图识别与执行.md>)

### [ ] 017 识别与改写流水线 · [原文](</Volumes/PortableSSD/docs/tengjiaozhai.github.io/thoughts/017_✅意图识别与问题改写的流水线编排.md>)

## 阶段验收

固定输入分别覆盖快速命中、改写后命中、LLM 兜底、多意图、续跑与并发隔离。此时可先让 Master/子 Agent 返回固定文字，确认**路由正确**后进入[阶段 C](阶段C-023-028.md)。
