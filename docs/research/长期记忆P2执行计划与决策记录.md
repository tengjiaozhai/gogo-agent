## 二、已接受的默认假设

- 守卫使用完整用户原话，不用截断文本。
- `id` 创建后持久化；REFINE 不改变 `id`。
- 退役条目保留原 `id` 与注释，并标注原因：`superseded`（被替代）、`refined`（被细化）、`evicted`（超出上限）。
- 同一条目文本在活跃集合中不重复（大小写不敏感）；与已有文本相同的 ADD 视为 NOOP。
- 抽取超时 8 秒，`max_tokens` 初始值 400，两者由模型层评测验证。
- 不做重试队列。
- ReMe 索引有约 8–10 秒延迟（本机实测）。这段时间内可能仍召回刚退役的条目，列为已知限制。
- 新模块 `memory_actions.py` 配套 `tests/test_memory_actions.py`。
